# Tech Zen Store — AI Product Storefront 🤖

A minimal, modern storefront webpage for an AI/tech product brand. Built as a front-end design exercise exploring clean e-commerce UI patterns.

## Stack

| | |
|---|---|
| Framework | React + TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| Build | Vite |

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
